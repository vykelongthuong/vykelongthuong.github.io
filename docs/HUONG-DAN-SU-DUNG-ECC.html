1. ECC hoạt động thế nào?

ECC là một bộ mở rộng cho Claude Code. Bạn vẫn dùng Claude CLI như bình thường, nhưng có thêm commands, agents, skills, hooks, rules.

Commands

Lệnh bạn chủ động gọi, ví dụ /plan, /code-review, /build-fix.

Agents

Subagent chuyên việc. Ví dụ reviewer, security reviewer, build resolver.

Skills

Workflow và kiến thức chuyên môn. Ví dụ TDD, security review, database migration.

Hooks

Tự chạy khi Claude dùng tool, edit file, bắt đầu/kết thúc session.

Mô hình dễ nhớ

Bạn gõ yêu cầu trong Claude CLI
        ↓
Commands: /plan, /build-fix, /code-review
        ↓
Skills: Claude biết nên làm theo workflow nào
        ↓
Agents: Claude giao việc cho chuyên gia phù hợp
        ↓
Hooks + Rules: tự kiểm tra format, security, quality
Nói ngắn gọn: Bạn vẫn vibe code bình thường. ECC giúp Claude có quy trình tốt hơn và tự kiểm tra nhiều hơn.

2. Cài đặt

Cách khuyến nghị: cài bằng plugin

Mở Claude CLI rồi gõ hai dòng này:

/plugin marketplace add https://github.com/affaan-m/everything-claude-code
/plugin install everything-claude-code@everything-claude-code

Sau đó restart Claude CLI.

Lưu ý: Nếu cài bằng plugin, nhiều lệnh có thể cần prefix /everything-claude-code:. Ví dụ /plan thành /everything-claude-code:plan.

Cách thủ công: cài từ source

Dùng khi bạn muốn kiểm soát profile, hooks, rules, hoặc đang phát triển chính ECC.

git clone https://github.com/affaan-m/everything-claude-code.git
cd everything-claude-code
npm install
npx ecc-install --profile full

Windows PowerShell

git clone https://github.com/affaan-m/everything-claude-code.git
cd everything-claude-code
npm install
.\install.ps1 --profile full --target claude

Kiểm tra cài đặt

node scripts/ecc.js list-installed
node scripts/ecc.js doctor

4. Commands chi tiết

Mỗi command dưới đây gồm: dùng khi nào, ví dụ bạn gõ, Claude sẽ làm gì.

/plan dùng nhiều nhất

Mục đích: Lập kế hoạch trước khi sửa code.

Dùng khi: Feature mới, refactor, bug phức tạp, thay đổi nhiều file.
/plan Thêm trang settings cho user, gồm đổi tên, đổi email, đổi mật khẩu

Claude sẽ: đọc cấu trúc project, tìm file liên quan, đề xuất bước làm, test cần chạy, rủi ro.

/code-review sau khi code

Mục đích: Review code vừa thay đổi.

Dùng khi: Bạn vừa để Claude code xong và muốn kiểm tra trước khi commit.
/code-review

Claude sẽ: xem diff, tìm bug, security issue, logic sai, test thiếu, cleanup cần làm.

/build-fix khi lỗi

Mục đích: Sửa lỗi build/test/lint.

Dùng khi: Terminal báo lỗi dài, bạn không muốn đọc hết.
/build-fix

Claude sẽ: chạy hoặc đọc lỗi build, tìm nguyên nhân gốc, sửa code, chạy lại kiểm tra.

/quality-gate trước commit

Mục đích: Kiểm tra chất lượng tổng hợp.

/quality-gate

Claude sẽ: kiểm tra test, lint, build, security cơ bản, docs nếu liên quan.

/refactor-clean dọn code

Mục đích: Dọn code chết, giảm duplication, đơn giản hóa.

/refactor-clean Dọn phần user profile component

Claude sẽ: tìm code không dùng, logic dư, abstraction thừa, rồi đề xuất/sửa gọn.

/test-coverage testing

Mục đích: Xem thiếu test ở đâu.

/test-coverage

Claude sẽ: chạy coverage nếu project hỗ trợ, phân tích vùng thiếu test, đề xuất test quan trọng.

/save-session ghi nhớ

Mục đích: Lưu trạng thái phiên để hôm sau quay lại.

/save-session

Dùng tốt nhất: trước khi tắt máy, trước khi chuyển task, sau khi debug được nửa chừng.

/resume-session tiếp tục

Mục đích: Khôi phục phiên cũ.

/resume-session

Claude sẽ: đọc snapshot phiên trước và tóm tắt việc đang làm.

6. Agents & Skills

Agents là gì?

Agent là chuyên gia nhỏ mà Claude có thể gọi để làm một việc riêng. Bạn thường không cần gọi trực tiếp; command/skill sẽ dùng khi cần.

code-reviewer

Review bug, quality, security, performance.

security-reviewer

Kiểm tra OWASP, secrets, injection, auth issue.

build-error-resolver

Đọc lỗi build/test và sửa root cause.

planner

Lập plan theo phase, file cần sửa, test cần chạy.

tdd-guide

Hướng dẫn Red → Green → Refactor.

e2e-runner

Chạy kiểm thử browser bằng Playwright.

Skills là gì?

Skill là workflow hoặc kiến thức chuyên môn. Bạn có thể yêu cầu Claude dùng skill bằng câu tự nhiên.

Dùng skill security-review để kiểm tra thay đổi hiện tại.
Dùng skill tdd-workflow để thêm chức năng delete todo.
Dùng skill database-migration để thiết kế migration an toàn.
Skills hữu ích cho vibe coding

7. Hooks

Hooks tự chạy khi Claude dùng tool. Bạn không cần nhớ nhiều, chỉ cần biết vì sao đôi khi Claude bị nhắc/chặn.

HookKhi nào chạyTác dụng
PreToolUseTrước khi Claude chạy toolCảnh báo command nguy hiểm, bảo vệ config
PostToolUseSau khi Claude edit/chạy commandKiểm tra quality, console.log, tích lũy thay đổi
StopKhi Claude dừng trả lờiFormat/typecheck/session evaluation
SessionStartKhi mở ClaudeLoad context dự án
PreCompactTrước khi nén contextLưu thông tin quan trọng

Nếu hooks làm phiền

Đặt profile nhẹ hơn:

# Windows PowerShell
$env:ECC_HOOK_PROFILE = "minimal"

# macOS/Linux
export ECC_HOOK_PROFILE=minimal

Tắt hook cụ thể:

export ECC_DISABLED_HOOKS="post:edit:typecheck,stop:desktop-notify"

8. MCP Servers

MCP là cầu nối để Claude truy cập công cụ ngoài như GitHub, Jira, Playwright, Context7, Exa, Supabase.

github

Làm việc với PR, issue, repo.

context7

Tra cứu docs mới nhất của thư viện.

playwright

Điều khiển browser để test UI.

exa-web-search

Tìm kiếm web chất lượng cao.

supabase

Làm việc với Supabase database.

memory

Lưu knowledge graph/bộ nhớ liên phiên.

Nên bật dưới 10 MCP server cùng lúc để không tốn context window.

10. Lỗi thường gặp

Tôi gõ /plan nhưng không thấy lệnh

Nếu cài bằng plugin, thử prefix đầy đủ:

/everything-claude-code:plan Thêm chức năng login

Kiểm tra plugin:

/plugin list everything-claude-code@everything-claude-code
Claude bị chặn không cho sửa file

Có thể là GateGuard yêu cầu điều tra trước. Đây là hành vi bảo vệ chất lượng. Nếu muốn tắt:

export ECC_GATEGUARD=off
Hooks chạy quá chậm 
export ECC_HOOK_PROFILE=minimal

Hoặc cài lại profile minimal.

node scripts/ecc.js repair --dry-run

11. Cheatsheet

Nhớ ít nhất các lệnh này

/plan <yêu cầu>        # Lập kế hoạch trước khi code
/code-review           # Review sau khi code
/build-fix             # Sửa build/test fail
/quality-gate          # Kiểm tra trước commit
/save-session          # Lưu phiên
/resume-session        # Khôi phục phiên

Câu mẫu copy dùng luôn

/plan Tôi muốn thêm chức năng [mô tả feature]. Hãy đọc codebase, đề xuất file cần sửa, test cần thêm, và rủi ro.

/code-review Review toàn bộ thay đổi hiện tại. Ưu tiên bug, security, edge cases, test thiếu.

/build-fix Build/test đang fail. Hãy tìm root cause, sửa tối thiểu, và chạy lại kiểm tra.

/quality-gate Kiểm tra thay đổi hiện tại đã đủ chất lượng để commit chưa.

/save-session Lưu lại trạng thái hiện tại, gồm việc đã làm, việc còn lại, file quan trọng, test đã chạy.

/plan → triển khai → /code-review → /quality-gate

Lỗi build

/build-fix, không sửa đại.

Cuối ngày

/save-session

Sáng hôm sau

/resume-session
